🦁 Zoo Website

A Zoo informational website built using HTML, CSS, JavaScript, and Bootstrap.
The website combines a single-page scrolling layout with multi-page routing to provide structured and easy navigation.

The site presents detailed information about animals categorized as Carnivores, Herbivores, and Omnivores, along with ticket pricing details for visitors. It also includes a contact form for enquiries.

Key Features:

Single-page scroll with multi-page navigation

Animal categories: Carnivores, Herbivores, Omnivores

Detailed animal information pages

Ticket price information

Contact form for user interaction

Responsive design using Bootstrap
